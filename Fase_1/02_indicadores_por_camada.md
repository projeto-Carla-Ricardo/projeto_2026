# Indicadores por Camada AILO — Critérios de Avaliação e Scoring

## Estrutura de Avaliação

Cada camada do AILO é avaliada através dos seus **componentes**, que por sua vez possuem **indicadores** específicos. Cada indicador é pontuado numa escala de **1 a 5** (níveis de maturidade).

### Escala de Maturidade AILO

| Nível | Nome | Descrição |
|-------|------|-----------|
| 1 | **Inicial** | Inexistente ou ad-hoc. Sem processos definidos. |
| 2 | **Em Desenvolvimento** | Reconhecido mas parcialmente implementado. Iniciativas isoladas. |
| 3 | **Definido** | Processos formais estabelecidos. Implementação consistente. |
| 4 | **Gerido** | Monitorização ativa. Dados utilizados para melhoria. |
| 5 | **Otimizado** | Melhoria contínua. Integração plena. Inovação sistemática. |

## Regras de Scoring

### Cálculo por Camada
```
Score_Camada = Σ(Score_Indicador × Peso_Indicador) / Σ(Peso_Indicador)
```

Todos os indicadores têm peso 1.0 por defeito, configurável pelo administrador.

### Cálculo do Índice Global AILO
```
Score_Global = Σ(Score_Camada × Peso_Camada) / Σ(Peso_Camada)
```

Pesos por defeito das camadas:
| Camada | Peso |
|--------|------|
| Organizacional | 1.0 |
| Humana | 1.2 |
| Aprendizagem | 1.0 |
| Cognitiva (IA) | 1.0 |
| Tecnológica | 0.8 |
| Avaliação | 1.0 |

> A Camada Humana tem peso ligeiramente superior (1.2) por ser fundacional em todos os estudos da revisão sistemática (CR2). A Camada Tecnológica tem peso ligeiramente inferior (0.8) por ser condição necessária mas não suficiente.

### Classificação Global
| Score | Nível | Interpretação |
|-------|-------|---------------|
| 1.0–1.8 | Inicial | Organização sem práticas estruturadas de aprendizagem mediada por IA |
| 1.9–2.6 | Em Desenvolvimento | Iniciativas isoladas, reconhecimento da necessidade |
| 2.7–3.4 | Definido | Práticas formais implementadas, integração parcial |
| 3.5–4.2 | Gerido | Monitorização ativa, dados utilizados para melhoria |
| 4.3–5.0 | Otimizado | Melhoria contínua, IA plenamente integrada, inovação |

### Análise de Interdependências
O motor deve avaliar pares de camadas críticos:
- **Humana × Avaliação** → Se ambas altas → double-loop learning provável
- **Cognitiva × Tecnológica** → Se cognitiva alta mas tecnológica baixa → risco de implementação
- **Organizacional × Humana** → Se organizacional alta mas humana baixa → estratégia sem execução
- **Avaliação × Cognitiva** → Se avaliação baixa → risco de bypass de absorção de conhecimento (CR5)
